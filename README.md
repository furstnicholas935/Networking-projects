# Networking-projects
#Enterprise Campus Network Architecture Lab Project Overview
-A simulated enterpris campus network designed and implemented using Cisco Modeling Labs (CML). This Project demonstrates network architecture, routing, switching, redundancy, and troubleshooting skills.
*NETWORKING ARCHITECTURE*
-Dual collapsed-core campus architecture
-Redundant WAN edge routers
-Layer 2 redundancy using multiple spanning tree (MST)
-First-hop redundancy using HSRP/VRRP/GRBP
-Dynamic routing using OSPF and BGP
-SD-WAN concepts including OMP and BFD
